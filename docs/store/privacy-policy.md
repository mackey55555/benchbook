# Benchbook プライバシーポリシー

最終更新日：【公開日を入れる】

Benchbook（以下「本アプリ」）は、バスケットボールの試合の記録をつけるためのアプリです。このページでは、本アプリが扱う情報について説明します。

## 1. 本アプリが集める情報

**本アプリは、利用者の情報を集めません。**

- 本アプリに入力した内容（チーム名、選手の氏名と背番号、試合の記録）は、お使いの端末の中だけに保存されます。開発者のサーバーや第三者には送られません。
- アカウントの登録はありません。
- 広告は表示しません。利用状況を調べるための解析ツールも入れていません。

## 2. 端末の外に情報が出るとき

次の場合に限り、情報が端末の外に出ます。いずれも、利用者ご自身の操作によるものです。

- **共有**：スコアシートや成績をPDF・画像で共有したとき、またはバックアップ（JSON）を書き出したとき。送り先は利用者が選びます。
- **アプリの更新確認**：本アプリは、新しい版があるかを配信サーバー（Expo Application Services）に問い合わせます。このとき送られるのはアプリの版の情報で、入力した記録は含まれません。

## 3. 選手の氏名について

本アプリには、利用者以外の方（選手など）の氏名を入力できます。入力した氏名は端末の中だけに保存されますが、共有したファイルには氏名が含まれます。共有する相手と範囲は、利用者の責任で決めてください。

## 4. 情報の削除

- 試合やチームは、アプリ内でいつでも削除できます。
- アプリを端末から削除すると、端末内の記録もすべて消えます。

## 5. 今後の変更

今後、複数の人で記録を共有する機能（チームプラン）を追加する予定です。その際は、アカウント情報や記録をサーバーで預かることになるため、このページを更新し、アプリ内でもお知らせします。

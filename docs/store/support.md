# Benchbook サポート

Benchbook は、バスケットボールのベンチで控えのスコアをつけるためのiPhoneアプリです。

## よくある質問

**記録はどこに保存されますか？**
お使いのiPhoneの中だけに保存されます。機種変更の前には、「設定 → バックアップ」で記録を書き出し、新しい端末で読み込んでください。

**間違えて入力した記録を直せますか？**
入力画面の「取り消す」で直前の記録を消せます。あとから直すときは、照合画面の「修正する」か、試合詳細の「得点・ファウルを直す」を使ってください。

**公式のスコアシートとして使えますか？**
使えません。本アプリの記録は控えで、公式記録ではありません。

**スコアシートや成績をほかの人に送れますか？**
試合詳細と分析の「共有」から、PDFまたは画像で送れます。
